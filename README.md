# Grupo Sertranin · presentación interactiva

Presentación corporativa para reuniones B2B en Piamonte. La portada permite abrir o descargar las versiones en español e inglés, en HTML interactivo o PowerPoint editable. Cada archivo HTML incluye todos los recursos necesarios para abrirlo sin conexión.

- `Sertranin_Interactive_Presentation_EN.html`: versión inglesa.
- `Sertranin_Presentacion_Interactiva.html`: versión española.
- `Sertranin_Presentacion_Interactiva_carpeta.zip`: ambas versiones y recursos en carpetas.
- `Sertranin_Corporate_Presentation_EN.pptx`: versión inglesa en PowerPoint (16 diapositivas).
- `Sertranin_Presentacion_Corporativa_ES.pptx`: versión española en PowerPoint (16 diapositivas).

El contenido desplegable de los ocho servicios del HTML se presenta en diapositivas separadas en el PowerPoint. Las notas de cada diapositiva conservan las aclaraciones de contenido.

La información procede del dossier corporativo de Sertranin, el texto facilitado para la intervención y la web de la empresa. El texto facilitado menciona dos almacenes bajo régimen aduanero en el área de Valencia, pero no incluye direcciones ni autorizaciones; conviene confirmar su situación antes de usar esa mención como acreditación formal.
